プライバシーポリシー

アプリ名：サブスクトラッカー - 定額サービス管理・解約リマインダー

開発者：吉田Web事務所（yoshida-web-office）

最終更新日：2026年5月28日

本ポリシーは、本アプリがユーザーの情報をどのように取り扱うかについて定めるものです。English version is available here.

1. 収集する情報と利用目的

1-1. ユーザーが入力する情報（端末内にのみ保存）

本アプリでは、以下の情報をお使いの端末内のローカルデータベース（Room）にのみ保存します。これらのサブスクリプション情報を外部サーバーへ送信することはありません。

  • サービス名
  • 金額
  • 支払いサイクル（月払い・年払い・週払い）
  • 次回請求日
  • カテゴリ
  • リマインダー設定
  • 無料トライアル終了日
  • メモ

これらは、本アプリの機能（支出の可視化・請求日リマインダー通知・統計表示）のために使用され、それ以外の目的では使用しません。

1-2. 自動的に収集される情報

本アプリは、サービス品質の向上と広告配信のため、以下の情報を第三者サービスを通じて収集することがあります。これらにサービス名・金額・メモなどの具体的なサブスクリプション内容は含まれません。

  • 利用状況の分析データ（Firebase Analytics）：画面表示・機能の利用回数などの匿名の統計情報
  • クラッシュ情報（Firebase Crashlytics）：アプリが異常終了した際の技術情報
  • 広告識別子（広告ID）（Google AdMob）：広告配信のため

2. 利用している第三者サービス

本アプリは以下の第三者サービスを利用しています。各サービスのデータの取り扱いについては、それぞれのプライバシーポリシーをご確認ください。

  • Google AdMob（広告配信）
    https://policies.google.com/privacy
  • Firebase Analytics（利用状況の分析）
    https://firebase.google.com/support/privacy
  • Firebase Crashlytics（クラッシュ解析）
    https://firebase.google.com/support/privacy

3. データの送信・共有

ユーザーが入力したサブスクリプション情報（サービス名・金額・メモ等）は、お使いの端末内にのみ保存され、第三者に送信・共有されることはありません。

Firebase Analytics による利用状況分析は、個人を特定しない匿名の統計情報としてのみ取り扱われます。

4. 広告について

本アプリは Google AdMob による広告を表示します。AdMob は広告のパーソナライズのために広告識別子（広告ID）を使用する場合があります。広告のパーソナライズは、端末の設定（設定 → Google → 広告）からオプトアウトできます。

5. データの削除

  • 個別削除：アプリ内でサブスクリプションごとに削除できます
  • 全削除：端末の設定 → アプリ → サブスクトラッカー → ストレージ → データを消去
  • アプリ削除：アプリをアンインストールすると、端末内のすべてのデータが削除されます

6. 免責事項

本アプリは、サブスクリプションの管理を補助するツールであり、表示される金額・請求日・統計は、ユーザーが入力した情報にもとづく参考値です。実際の請求内容については各サービスの公式情報をご確認ください。本アプリの利用により生じた損害について、開発者は一切の責任を負いかねます。

7. ポリシーの変更

本ポリシーは、必要に応じて改訂されることがあります。重要な変更がある場合は、アプリ内またはストア掲載情報でお知らせします。
